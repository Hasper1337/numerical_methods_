# GraphPlotter — лабораторные работы 1–8 (C# / WinForms, .NET 8)

Одно приложение, каждая лабораторная — отдельная вкладка (`UserControl`).
Интерфейс собран в конструкторе Visual Studio (файлы `*.Designer.cs`), логика — в коротких обработчиках.

| Вкладка | Файлы | Что делает |
|---|---|---|
| 1. Визуализация | `Lab1Control` | график по формуле или по текстовому файлу (2 колонки), масштаб колесом мыши, сдвиг перетаскиванием |
| 2. Уравнение | `Lab2Control` | корень `x²−3−2cos(2πx)=0` методом парабол, ε=1e-4, таблица итераций, f(x*), число итераций, zoom к корню |
| 3. Экстремум | `Lab3Control` | минимум/максимум методом парабол, f′ и f″ в найденной точке, тип экстремума |
| 4. Определитель | `Lab4Control` | метод Гаусса с выбором главного элемента по столбцу + проверка разложением по минорам |
| 5. СЛАУ | `Lab5Control` | метод релаксаций (SOR), ε по max\|Δx\|, решение и невязка |
| 6.3 Наим. квадраты | `Lab63Control` | вариант 5: многочлены 4–5 степени, показательная, логарифмическая, шум 30–300 %, выбор лучшей |
| 7. Интеграл | `Lab7Control` | метод левых прямоугольников с автоматическим удвоением сетки |
| 8.1 Вторая производная | `Lab81Control` | формулы второго и четвёртого порядка |
| 8.2 ОДУ | `Lab82Control` | решение методом Эйлера |

Лабораторные 7–8 соответствуют варианту 21. Для интегрирования по умолчанию используется отрезок `[0;1]`; точка и шаги для второй производной задаются в интерфейсе, как и шаг интегрирования ОДУ. ОДУ решается явным методом Эйлера.

Для графиков во всех лабораторных используется общий `GraphControl` с масштабированием колесом мыши и сдвигом перетаскиванием.

Общие файлы: `GraphControl.cs` (рисование), `ExpressionEvaluator.cs` (формулы), `Methods.cs` (численные методы лабораторных 1–6), `Util.cs` (мелкие помощники), `Lab78Control.cs` (лабораторные 7, 8.1 и 8.2).

Запуск: `dotnet run` в папке проекта или открыть `GraphPlotter.csproj` в Visual Studio 2022. Формы открываются в дизайнере (двойной щелчок по `*.cs`) после первой сборки.
